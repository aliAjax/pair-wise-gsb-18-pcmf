# hxwl-04 牙科根管治疗

按单颗牙推进根管治疗：开髓 → 测长 → 根管预备 → 封药 →（登记复诊）→ 充填

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5104

## 功能

- 按牙位（FDI）建案，初诊即记录开髓；同一牙位未完成前不可重复建案
- 每次接诊追加一个阶段（开髓/测长/根管预备/封药/充填），历史记录只读、不可改写
- 流程校验：跳步时明确指出缺少的步骤；已封药但未登记复诊日期的牙位禁止充填
- 牙位、主尖锉号、工作长度随病案带走，追加复诊时自动预填
- 指标看板（待复诊、已充填、平均工作长度、封药病例）、牙位列表与病历摘要同源同步
- 病历摘要一键复制；数据存 localStorage，下次打开接着处理
