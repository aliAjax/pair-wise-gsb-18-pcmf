# hxwl-04 牙科根管治疗

按**单颗牙**推进根管治疗的接诊工作台。

## 技术栈

React 19 + Vite 7 + TypeScript + 原生 CSS（数据保存在浏览器 localStorage）

## 本地运行

```bash
npm install
npm run dev      # 开发：http://localhost:5104
npm run build    # 类型检查后产物构建
```

开发端口：5104

## 业务规则

- **按牙位推进**：步骤固定为 开髓 → 测长 → 根管预备 → 封药 → 复诊登记 → 充填；每颗牙的阶段必须按顺序追加（封药后也允许跳过封药直接充填，即一次性根充）。
- **每次接诊记录一个阶段**：记录开髓、测长、根管预备、封药或充填，含接诊日期、工作长度、主尖锉号、备注。
- **已封药未登记复诊不能充填**：此时步骤条中「复诊」红闪并标注**缺少步骤：复诊登记**，充填入口关闭，阻断原因直接显示在表单和卡片上；先登记复诊（含计划复诊日期）后才放行。
- **复诊只追加，不改写旧记录**：新接诊追加到时间线末尾；历史条目的日期与快照永不修改。
- **参数带走**：选中牙位继续处理时，牙位、诊断、最近一次工作长度、主尖锉号自动带入表单；值可在新记录中更新，旧条目保持原样。
- **同步派生**：牙位列表、待复诊数量、指标看板（管理牙位 / 待复诊 / 已充填 / 平均工作长度 / 封药病例数）、病历摘要全部由数据实时计算；摘要可一键复制。
- **持久化**：所有数据写入 localStorage（`rct-cases-v1`），下次打开继续处理；可一键恢复演示数据。
